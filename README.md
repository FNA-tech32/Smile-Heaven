**Smile Heaven** is a premier dental healthcare web application showcasing advanced implantology, cosmetic dentistry, full-mouth rehabilitation, and dental tourism services based in Puducherry, India. Crafted with a luxury aesthetic, modern typography, glassmorphism UI elements, and fluid animations.

---

## 🌟 Key Features

- **💎 Luxury & Trust-Centric Aesthetic**: Deep navy, clinical teal, and warm gold accents designed to instill patient confidence and tranquility.
- **📱 Responsive Navigation & Mobile Drawer**: Glassmorphism navbar with scroll detection, appointment triggers, direct dialing, and an animated drawer for mobile devices.
- **⚡ Dynamic Hero Suite**: Interactive trust counters (99.2% implant success, 4.7★ Google Rating, 40+ reviews), floating badges, and instant booking/WhatsApp triggers.
- **🏥 Comprehensive Clinical Sections**:
  - **About Clinic**: Sterile protocols, high-precision CBCT digital workflow, and clinic standards.
  - **Specialized Treatments**: Detailed service breakdown for Dental Implants, Immediate Loading, Full Mouth Rehab, Smile Makeovers, Root Canals, and Cosmetic Dentistry.
  - **Why Choose Us**: Modern diagnostics, minimally invasive techniques, and lifetime warranty implant systems.
  - **Specialist Profile**: Clinical director profile highlighting MDS certifications, international fellowships, and surgical experience.
  - **Dental Tourism Portal**: Travel coordinates, international patient concierge support, and price comparison ($700–$950 vs. $3,500–$4,500 in US/Europe).
  - **Patient Testimonials**: Verified local and international patient reviews.
  - **Media Gallery**: High-definition operatory, sterilization room, and lounge previews.
  - **Interactive Booking & Contact Suite**: Multi-field consultation request form with feedback state and embedded Google Maps location.
  - **Footer Suite**: Complete navigation index, treatment directory, social links, and clinic contact matrix.

## 🚀 Getting Started

### Prerequisites

Ensure you have [Node.js](https://nodejs.org/) (v18.0 or newer recommended) and `npm` installed on your machine.

### Installation

1. Clone or navigate to the repository directory:
   ```bash
   cd Smile-Heaven
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

### Development Server

Start the local Vite development server:
```bash
npm run dev
```
Open your browser and navigate to `http://localhost:5173/` (or the port specified in terminal).

### Production Build

To build the project for production deployment:
```bash
npm run build
```
The optimized static production bundle will be generated in the `dist/` folder.

### Preview Production Build

To preview the production build locally:
```bash
npm run preview
```
